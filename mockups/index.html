Mockups

Standalone HTML screens for design review. Every page opens straight in a browser — no build step, no server, no framework — and they all share one stylesheet and one shell. These are not the production app.

Screens

Four patterns, built to cover the shapes every later page falls into: an overview, a list, a create flow and a record. On the Dashboard, the Live data menu in the top bar switches between the live, loading, empty and error states — that menu is a review control, not a product feature.

Dashboard Ready What needs a decision today, the four headline numbers, spend against conversions, spend by platform, an AI Planner suggestion and the top campaigns. Campaigns Ready The list pattern: status tabs with counts, a full toolbar, two-line rows, pacing meters, bulk selection and per-row actions. New campaign Ready The create pattern: three steps, a running summary that shows which values were inherited, and hints that explain each platform constraint. Campaign detail Ready The record pattern: metrics, child records, an activity log, and a right rail holding the facts, pacing and audience overlap.

Design system

Every token lives in assets/tokens.css and nowhere else. Pages reference variables; no page hardcodes a colour. Both themes are drawn deliberately — dark is its own set of values, not an inverted light. One type family throughout, with a 14px floor.

Platform colours identify a brand beside its name, as a dot. They never carry a value on their own: Meta blue and LinkedIn blue are too close to tell apart as chart fills, and TikTok's black has no hue to read.

Both steps clear the lightness band, chroma floor, colour-vision-deficiency separation, normal-vision floor and 3:1 contrast against the chart surface, in light and dark. Charts also keep a legend and a data table, so identity never rests on colour alone.
